# Robs-garage-app

my app is one of a kind personal service requesting app that allows mechanics to be booked.

## Mobile mechanic booking app 

A cross- platform mobile appbuild with React Native and Firebase that allows users to book mobile mechanic service, trach job status, and manage bookings.

## Features
- User Authentication
- Service Listing
- Booking Management
- Mechanic Profiles
- Firebase Backend (afirebase, Auth, Storage)

## Getting Started
1. Clone the repo
2. Run 'npm install'
3. Set up Firebase and replace config in 'firebase/firebase-config.ts'
4. Run app with 'npx expo start'
